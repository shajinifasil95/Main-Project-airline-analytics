✈️ Airline Analytics
📌 Project Description

Airline Analytics is a data analytics project that analyzes airline customer behavior, flight activity, loyalty program engagement, travel patterns, spending, and customer value.

The project uses Python for data preprocessing, exploratory data analysis (EDA), statistical analysis, and visualization. Power BI is used to create interactive dashboards and present business insights.

The main goal of this project is to discover patterns and trends in airline customer data and support evidence-based business decision-making.

🎯 Objectives

Analyze airline customer demographics.
Analyze flight frequency and travel behavior.
Study customer spending and revenue patterns.
Analyze Frequent Flyer Program (FFP) loyalty tiers.
Examine customer points and redemption behavior.
Analyze travel distance and flight activity.
Identify high-value customers.
Identify potentially inactive customers.
Understand relationships between flights, spending, loyalty, and customer value.
Create interactive Power BI dashboards.
